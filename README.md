# 🎨 Free tools for artists · เครื่องมือฟรีสำหรับศิลปิน

Open-source tools that help artists **protect their work, run their business and spot fakes**.
Everything runs in your browser — **your files are never uploaded**. Thai + English.

เครื่องมือโอเพนซอร์สช่วยศิลปิน **ปกป้องผลงาน จัดการงาน และจับของปลอม**
ทุกตัวทำงานในเบราว์เซอร์ **ไฟล์ของคุณไม่ถูกอัปโหลดไปไหน** ใช้ฟรี ไม่ต้องสมัคร

---

## 🔏 Protect your work · ปกป้องผลงาน

| Tool | What it does | |
|---|---|---|
| **[Inkseal](https://github.com/ronsuthlor3-lab/inkseal)** | Seal artwork with your handwriting, an unforgeable digital signature and an invisible creator ID<br>ประทับตราด้วยลายมือ ลายเซ็นดิจิทัลที่ปลอมไม่ได้ และรหัสผู้สร้างล่องหน | [▶ Open](https://ronsuthlor3-lab.github.io/inkseal/) |
| **[Inkseal Scanner](https://github.com/ronsuthlor3-lab/inkseal-scanner)** | Browser extension that spots your hidden creator ID on web pages<br>ส่วนเสริมเบราว์เซอร์ ช่วยเจอรูปที่มีรหัสผู้สร้างของคุณ | [Install guide](https://github.com/ronsuthlor3-lab/inkseal-scanner#readme) |
| **[Inkcloak](https://github.com/ronsuthlor3-lab/inkcloak)** 🧪 | *Experimental, unproven* perturbation against AI style mimicry — not a substitute for Glaze/Nightshade<br>*รุ่นทดลอง ยังไม่พิสูจน์ผล* | [▶ Open](https://ronsuthlor3-lab.github.io/inkcloak/) |

### Honest by design · บอกข้อจำกัดตรงๆ

No tool can stop theft or fraud 100%. Each project's README states plainly what it **can and cannot** do.
ไม่มีเครื่องมือไหนกันการขโมยหรือโกงได้ 100% ทุกโปรเจกต์เขียนบอกชัดเจนว่า **ทำอะไรได้และทำอะไรไม่ได้**
